About PhishLens

PhishLens is a modern, AI-powered malicious URL detection engine built to proactively safeguard internet users from credential-harvesting cyberattacks.

The Problem with Traditional Blacklists

Traditional cybersecurity filters rely on centralized blacklists of previously reported domain names. However, over 60% of modern phishing domains stay active for less than 24 hours. Attackers register algorithmic domain variations, harvest credentials, and abandon the domain before security vendors can inspect or blacklist it.

PhishLens bridges this security window by examining the inherent anatomical properties of the link—such as subdomain depth, symbol ratios, and Shannon character entropy—using machine learning to detect zero-day threats without relying solely on prior reports.

The Machine Learning Pipeline

  1. 1. Safe Input Ingestion: The URL string is parsed syntactically without opening or executing the target destination.
  2. 2. Feature Decomposition: 15 distinct lexical, structural, and information-theoretic features are calculated.
  3. 3. Random Forest Classification: An ensemble of decision trees computes prediction probability against learned threat profiles.
  4. 4. Explainable Verdict: A risk score from 0 to 100 is presented alongside plain-language justifications for transparency.

Privacy & Ethical Standards

PhishLens enforces strict privacy safeguards: sensitive URL parameters containing tokens or passwords are redacted, scan history is kept non-persistent in session memory, and target links are never executed server-side to eliminate SSRF risks.
