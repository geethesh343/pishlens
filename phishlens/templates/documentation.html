15 URL Detection Features Taxonomy

# Feature Name Pillar Rationale
1 url_length Lexical Phishing links often exceed 75 characters to hide real target domains on mobile viewports.
2 hostname_length Structural Long hostnames frequently contain nested brand spoofing.
3 dot_count Structural Unusual frequency of dots indicates excessive subdomain chaining.
4 hyphen_count Lexical Typosquatting domains frequently use hyphens (e.g. paypal-security-auth).
5 digit_count Lexical High digit counts indicate automated campaign identifiers.
6 has_at_symbol Lexical The @ symbol causes browsers to ignore all preceding characters.
7 subdomain_count Structural Exploits right-to-left host parsing to mimic trusted domains.
8 is_ip_address Structural Detects raw IP hosts (e.g. http://192.0.2.10/...) used to bypass DNS filtering.
9 is_https Security Unencrypted HTTP links are unusual for authentic banking portals.
10 path_length Structural Measures path nesting depth.
11 query_param_count Structural Tracks query arguments often used to forward stolen session keys.
12 suspicious_token_count Lexical Matches credential keywords (login, verify, banking).
13 character_entropy Entropy Shannon entropy $H(X) = -\sum P(x) \log_2 P(x)$ detects botnet DGA links.
14 has_unusual_port Structural Flags ports other than 80 or 443 (e.g. 8080, 8443).
15 has_encoded_chars Lexical Detects hex escape sequences (%20, %2e) used to evade pattern matchers.

REST API Endpoints

POST /api/predict

Accepts a JSON payload {"url": "https://..."} and returns the 15 features, probability, risk score, and plain-English signals.

GET /api/health

Returns health status, uptime, and model loading state.

GET /api/stats

Returns real session scan counters and model test metrics.

GET /api/model-info

Returns model architecture, scikit-learn version, and feature configuration.
